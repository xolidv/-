# Конспект по теме

Школьный проект по созданию веб-сервиса, который собирает краткий учебный конспект по заданной теме. Конспект можно будет прочитать на странице, сверить с источниками и скачать в PDF для повторения или печати.

## Зачем нужен проект

Сервис нужен школьникам, которые хотят быстрее подготовить конспект для повторения темы. Он выделяет главное и собирает материал в короткие блоки по одной структуре. По ссылкам на источники можно проверить сведения и подробнее разобраться в теме.

## Как будет работать первая версия

1. Ученик вводит тему и уточняет, что должно попасть в конспект. Например, для закона Ома можно попросить формулу, объяснение обозначений и пример задачи.
2. Сервис подбирает материалы и составляет конспект со ссылками на источники. В конспекте есть ключевые понятия, краткое объяснение, разобранный пример и вопросы для самопроверки.
3. Ученик просматривает конспект на странице и скачивает PDF, пригодный для печати.

В первой версии будет текстовый ввод и один шаблон PDF. Следующий шаг — загрузка фотографии параграфа, чтобы составлять конспект по тексту учебника.

## Как проверим результат

Подготовим образец конспекта на одну страницу. Затем дадим нашему сервису и нескольким ИИ-чатам одну школьную тему и одинаковые требования к конспекту. Сравним, какие ключевые пункты вошли в каждый ответ, есть ли лишние детали, насколько легко проверить сведения и удобно ли распечатать результат. В описании проекта покажем примеры и объясним оценки по этим критериям.
