# Конспект по теме

Школьный проект по созданию веб-сервиса, который собирает краткий учебный конспект по заданной теме. Конспект можно будет прочитать на странице, сверить с источниками и скачать в PDF для повторения или печати.

## Зачем нужен проект

Когда ученик пропустил урок или хочет повторить тему, ему приходится искать материалы, выбирать главное и собирать всё в один документ. Мы хотим сократить время на эту подготовку и дать ученику возможность проверить, откуда взялись сведения.

## Как будет работать первая версия

1. Ученик вводит тему, например «Закон Ома, 8 класс».
2. Сервис подбирает материалы и составляет конспект со ссылками на источники. В конспекте есть ключевые понятия, краткое объяснение, разобранный пример и вопросы для самопроверки.
3. Ученик просматривает конспект на странице и скачивает PDF, пригодный для печати.

Начинаем с ввода темы текстом и одного шаблона PDF. Позже можно добавить распознавание темы с фотографии и конспекты по аудиозаписи урока.

## Как проверим результат

Возьмём одну школьную тему и подготовим эталонный конспект на одну страницу. Сравним с ним результат сервиса и проверим, что объяснение соответствует уровню класса, ссылки ведут к материалам по теме, а PDF сохраняет структуру и читается при печати.
